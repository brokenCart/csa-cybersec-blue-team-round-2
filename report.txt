INCIDENT REPORT

1. Executive Summary

On 15 March 2024, between 08:45 and 12:04 UTC, the web application was targeted by eight IP addresses using three distinct attack types: brute-force login attacks (30 failed logins from 4 IPs), SQL injection (10 attempts from 3 IPs), and directory traversal (11 attempts from 3 IPs). The attacks targeted the login endpoints (/login, /admin/login, /api/login, /wp-login.php), database-backed pages and APIs (/search, /products, /login, /api/items), and file-serving paths (/download, /static, /files, /img, /view, /get). One IP, 141.98.10.33, used all three attack types within about four minutes. The overall severity is HIGH because the log contains signs that some attacks may have succeeded: 203.0.113.42 received a 200 response to POST /login at 08:46:00, immediately after 12 failed logins, and this was the only successful POST to a login endpoint by any of the attacker IPs, which suggests a possibly compromised account. In addition, ' OR 1=1 requests from 185.220.101.5 and 141.98.10.33 returned 200, all three DROP TABLE requests that were not blocked returned 500, and a traversal request for /etc/hosts from 88.198.50.20 returned 200. The log records only response codes, so these outcomes need to be confirmed against application and database records.

3. Recommended Actions

Brute Force: Enforce rate limiting and temporary account lockout after repeated failed logins on all login endpoints.

SQL Injection: Use parameterized queries for all database access so that user input is never executed as SQL.

Directory Traversal: Resolve each requested file path to its canonical form and reject any path outside an allowed base directory.
